IoT Based Weather Monitoring System

Overview

The **IoT Based Weather Monitoring System** is designed to measure and monitor environmental parameters such as temperature, humidity, atmospheric pressure, and rainfall in real time. The system uses IoT technology to transmit data to the cloud, enabling remote monitoring through a web dashboard or mobile application.

This project demonstrates the practical application of embedded systems and IoT for environmental monitoring.

---

Objectives

* Measure temperature and humidity
* Monitor atmospheric pressure
* Detect rainfall conditions
* Transmit data to cloud using IoT
* Display real-time data locally and remotely

---

 Technologies & Components

 Hardware

* ESP32 Microcontroller
* DHT11 Temperature & Humidity Sensor
* BMP180 Pressure Sensor
* Rain Sensor
* 16×2 LCD Display (I2C)
* Breadboard & Jumper Wires

 Software

* Arduino IDE
* Embedded C Programming
* IoT Cloud Platform (HTTP / MQTT)

---

Working Principle

1. Sensors collect environmental data
2. ESP32 processes the data
3. Data is converted into meaningful units
4. Processed data is transmitted via Wi-Fi
5. Data is displayed on LCD and cloud dashboard

---

 System Flow

* Initialize sensors
* Read sensor data
* Process & validate data
* Display data on LCD
* Send data to cloud
* Repeat continuously
